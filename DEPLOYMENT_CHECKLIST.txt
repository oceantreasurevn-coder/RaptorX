TROUBLESHOOTING
════════════════════════════════════════════════════════════

If website doesn't load:
- Wait longer for DNS (can take 30 min)
- Check GitHub Pages settings
- Verify CNAME in Hostinger

If API doesn't respond:
- Check Render service is "Live"
- Verify environment variables
- Check Render logs

If DNS not resolving:
- Run: dig scaterraptorx.eu
- Flush DNS: sudo dscacheutil -flushcache (Mac)
- Wait longer (DNS takes time)

If HTTPS not working:
- Wait 1-2 minutes
- Check "Enforce HTTPS" is enabled
- Refresh browser
